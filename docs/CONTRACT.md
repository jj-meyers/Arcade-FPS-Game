# Implementation contracts

Browser-native JavaScript modules. Three.js only in rendering. Simulation uses plain objects and fixed 1/60-second steps. Positions are feet coordinates, +Y up. Forward vector for yaw/pitch: `{x: -sin(yaw)*cos(pitch), y: sin(pitch), z: -cos(yaw)*cos(pitch)}`. Positive pitch looks up. Arena bounds ±28.

## Catalog (combat owns src/data/catalog.js)
Export object maps `WEAPONS`, `GADGETS`, `PERKS`, `PRESETS` and object `DEFAULT_LOADOUT`. Every definition has id/name/description/color. Weapons have category, damage, fireInterval, magazine, reserve, reloadTime, range, spread, automatic, kind (hitscan/projectile), plus mechanics. Gadgets have slot (`tactical`/`lethal`), cooldown and mechanic. Perks describe actual modifiers; IDs `spring`, `heavy`, `quick`. Loadout shape `{primary,secondary,tactical,lethal,perk}`. Seven weapon IDs: `fizz`, `doorbell`, `bankshot`, `confetti`, `rail`, `updraft`, `yoink`. Gadget IDs: `springpad`, `bubble`, `vortex`, `cherry`, `whoopee`. Presets map IDs to `{id,name,description,loadout}`.

## Game (main agent owns src/game/Game.js, physics.js, math.js, src/data/arena.js)
`new Game({seed,settings,loadout})`. `game.start(matchConfig,loadout)`, `game.step(dt,input)`, `game.setPaused(bool)`. `game.actors`, `game.player`, `game.map`, `game.time`, `game.rng()`; `game.match={state:'menu'|'countdown'|'playing'|'ended',countdown,remaining,scoreLimit,difficulty,botCount,duration,winnerId}`. Menu initially has demo actors for presentation, but no simulation. `game.events` queued plain objects; root drains after updates. `game.emit({type,...})`. `game.paused` separate.

Actor fields: `id,name,isPlayer,color,personality,pos:{x,y,z},vel:{x,y,z},yaw,pitch,radius:0.45,height:1.8,health,maxHealth,alive,grounded,kills,deaths,respawnAt,invulnerableUntil,equipment:{primary,secondary,tactical,lethal,perk},activeSlot:0|1,inventory:{},gadgetReady:{},ai:{}`. Core moves actors from `actor.intent={moveX,moveZ,sprint,jump,crouch}` world-space normalized direction; player input moveX/moveZ is local (right/forward). `actor.lastDamagedBy`, `actor.lastDamageAt` useful to AI. `game.damage(target,amount,{attackerId,weaponId,headshot,impulse:{x,y,z}})` ignores dead/invulnerable actors, applies impulse and emits damage/eliminate events. `game.addImpulse(actor,vec)` handles perk resistance. Core respawns, invokes `combat.equip(actor)` to reset inventory. `game.getActor(id)`.

`game.raycast(origin,dir,range,ignoreId=null)` returns nearest hit `{point,normal,distance,actor:null|actor,headshot,obstacle}` or null; includes environment, living actors and arena floor/walls. `game.worldRaycast(origin,dir,range)` excludes actors. `game.canSee(a,b)` uses eye-to-chest segment and world occlusion. `game.eye(actor)` returns eye position. Vectors dirs normalized by caller. `game.groundHeight(x,z)` returns ramps/platform height (physics).

`game.map={size:56,obstacles:[{id,x,y,z,w,h,d,color}],ramps:[{id,x,z,w,d,h,color}],spawns:[{x,y,z}],pads:[...]}`. Obstacles x/z are center, y is bottom; axis-aligned boxes. Ramps rise along +Z from y=0 to h. AI treats obstacles and ramps conservatively in grid.

Input `game.step(dt,{moveX,moveZ,yaw,pitch,sprint,crouch,jump,fire,alt,reload,switchSlot,tactical,lethal})`; edges jump/reload/switchSlot/tactical/lethal consumed by root on first step; switchSlot is null or 0/1. Fire/alt held. Core runs combat.fire() for player; combat handles cadence.

## Combat (agent owns src/game/Combat.js, src/data/catalog.js)
`new Combat(game)`. `equip(actor)`, `getWeapon(actor)`, `getWeaponState(actor)`, `switchWeapon(actor,slot)`, `reload(actor)`, `fire(actor,dir,alt=false)` (muzzle from game.eye), `useGadget(actor,slot,dir)`, `update(dt)`. State fields `{ammo,reserve,reloadEnd,nextFire}`. `combat.projectiles` objects `{id,pos,vel,color,radius,kind,ownerId,...}`; `combat.fields` objects `{id,pos,radius,kind,color,expires,ownerId,...}`. Mechanics should use reusable splash/impulse routines and world occlusion. Projectiles swept segment checks, grenade/bounce floor collision, shield absorb and vortex interactions. Events: `shot` with actorId,weaponId,origin,point,color; `impact` point/color; `explosion` point/radius/color; `gadget` actorId,gadgetId,point; `reload` actorId; `switch` actorId. Core emits `damage` actorId,attackerId,amount,headshot,point and `eliminate` actorId,attackerId,weaponId,point,color; `spawn`, `jump`, `land`, `matchEnd`, `matchStart`. Renderer can tolerate unknown.

## AI (agent owns src/game/AI.js and navigation.js)
`new AI(game)`; `update(dt)`. Only called during active match before physics. Per-bot `actor.ai` state. Update bot world-space intent and yaw/pitch; shoot/reload/gadget via combat. Use visible targets only, short last-seen memory, hearing from lastDamageAt allowed. Can target every other actor (FFA). Three behavioral difficulty tiers. Navigation around boxes, stuck recovery, reaction latency, predictive imperfect aim. Use game RNG for reproducibility.

## Render (agent owns src/render/Renderer.js)
`new Renderer(canvas,game,settings)`; `resize()`, `applySettings(settings)`, `render(dt,alpha=1)`, `handleEvents(events)`, `dispose()`. Resize on window resize. Uses game state, actor transforms, combat projectile/field arrays. Render menu presentation in same scene using orbit camera; active player view in match (including pause). Procedural mascot bots, distinct weapon silhouettes, graybox arena. Screen/UI handled elsewhere. Fields recognizable, traces/particles bounded and cleaned. Camera FOV, quality, renderScale, shake settings real. Keep weapon in viewmodel scene so no clipping through walls. Do not import main/UI. Expose renderer.renderer (Three WebGLRenderer) and camera for tests.

## UI (agent owns src/ui/UI.js and style.css)
`new UI(root,{onStart(config,loadout),onPause(),onResume(),onMenu(),onSettings(settings),onFullscreen(),onRestart()})`; `showMenu()`, `showPause()`, `hidePause()`, `showResults(game)`, `update(game,dt)`, `handleEvents(events,game)`, `showScoreboard(bool,game)`, `notify(text)`. `ui.settings`, `ui.loadout`, `ui.matchConfig` persistent via versioned localStorage, tolerate corrupted data. `ui.startGame()` invokes callback and hides menu; `ui.isOverlayOpen` boolean. UI mounts overlays/HUD and is responsible for menu navigation. Settings shape `{sensitivity:1,fov:85,masterVolume:.7,sfxVolume:.8,quality:'high',renderScale:1,crosshair:'cross',shake:.5}`. Match config `{botCount:5,difficulty:'normal',duration:180,scoreLimit:20}`. Full menu with main overview, match setup, loadout cards, settings, pause, results. Keyboard shortcuts root handles; show WASD mouse LMB RMB R Shift Space 1/2 Q E Tab Esc instructions. UI should distinguish paused vs pointer lock prompt. Core onStart only called directly from click so root can acquire pointer lock immediately.

## Main (main agent)
Owns src/main.js, input/audio, Game and physics, tests and docs. Browser automation debug API under `?debug`: `window.__CHAOS__={game,ui,renderer,start(config,loadout),advance(seconds)}`. Render dt and fixed simulation accumulator. If pointer lock lost, pause active/countdown; resume on click; menu/result releases lock. Avoid live-process assumptions. No network gameplay or external assets.
